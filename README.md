# sme-financial-webapp
Final Year Project — A web-based SME Financial Health Platform providing financial scoring, insights, recommendations, trend forecasting, and AI-powered receipt/document extraction, built with Next.js, FastAPI, PostgreSQL, Redis, Celery, and cloud-based services.


## Current integration branch

**`codex/fatima-secure-frontend` contains all frontend source developed so far, on top of Suleman's integrated backend and security code.** Nothing needs to be copied from `dev/fatima` to run the current frontend. Main is unchanged.

Start with the [consolidated branch guide](docs/CONSOLIDATED_APP_BRANCH.md) for the verified branch comparison, what is implemented, and what still needs completion or production verification. See [frontend setup](frontend/README.md) and the [integration handoff](docs/frontend-security-integration-2026-09-27.md).
